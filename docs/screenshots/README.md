# اسکرین‌شات‌های رندر‌شده در CI

این تصاویر با `flutter test test/screenshot_test.dart`، فونت
Vazirmatn باندل‌شده و assetهای واقعی پروژه در GitHub Actions
رندر شده‌اند. برای بازبینی طراحی، چیدمان و RTL مفیدند، اما
**اسکرین‌شات گوشی واقعی نیستند** و آزمون لمس/پخش روی دستگاه را
جایگزین نمی‌کنند. ترتیب فایل‌ها جریان
Splash → Home → Categories → Search → Detail است.

نکته: اموجی‌های سیستم (آواتار کودک) در هارنس تست flutter
رندر نمی‌شوند و جای‌شان خالی می‌ماند؛ روی دستگاه واقعی
اندروید درست نمایش داده می‌شوند. نشان‌های دسته و سرتیترها
برداری‌اند و در همین تصاویر هم کامل دیده می‌شوند.
