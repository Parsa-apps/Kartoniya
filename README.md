# 🎬 کارتونیا — فضای امن و شاد کودکان

**کارتونیا** یک اپلیکیشن Flutter فارسی و RTL برای پیدا کردن و تماشای محتوای کودک است. تجربهٔ برنامه برای کودک ساده و رنگی طراحی شده و بخش تنظیمات والدین با یک مسئلهٔ ریاضی تصادفی محافظت می‌شود.

> وضعیت فعلی: نسخهٔ ۱.۲.۰ با Design System و Motion System منسجم (پالت آبی آسمانی/فیروزه‌ای/بنفش/مرجانی/طلایی، ماسکٔ رابط «فِلَک»، بنر محتوای منتخب، Hero Transition، نوار پیمایش اختصاصی، کاهش حرکت والدین)، کاتالوگ محلی، پخش‌کنندهٔ واقعی ویدئو، تنظیمات پایدار روی دستگاه و مسیر آماده برای اتصال به API/CMS. محتوای نمایشی (کاتالوگ محلی و URL نمونهٔ ویدئو) باید پیش از انتشار با ویدئوهای دارای مجوز جایگزین شود.

## قابلیت‌ها

- رابط **Material 3**، فارسی و کاملاً RTL با حالت روشن/تاریک منسجم
- **فونت Vazirmatn به‌صورت asset باندل شده** (OFL) — بدون وابستگی شبکه در اولین اجرا و cold start سریع‌تر
- **Motion System** مشترک در `AppMotion`: ورود پلکانی، مقیاس لمسی، ترنزیشن یکنواخت صفحات، Hero Transition بنر→جزئیات، بازخورد انفجاری علاقه‌مندی و احترام به «کاهش حرکت»
- خانه با بنر محتوای منتخب (چرخش خودکار + پارالاکس)، ردیف‌های تازه‌ها/محبوب‌ها، ادامهٔ تماشا با درصد واقعی و حلقهٔ پیشرفت
- Splash برندینگ‌شده و Onboarding سه‌مرحله‌ای با ماسکٔ رابط و پس‌زمینهٔ شفق برداری
- دسته‌بندی با کاشی‌های رنگی و شمارش واقعی، جست‌وجوی فارسی با normalize حروف، فیلتر دسته و نتایج مرتب‌شده
- علاقه‌مندی‌ها و ادامهٔ تماشا با پاک‌سازی خودکار شناسه‌های نامعتبر هنگام بارگذاری کاتالوگ
- پخش‌کنندهٔ واقعی با `video_player`: بافر نمایشی، دابل‌تپ ۱۰ ثانیه‌ای، شمارش معکوس «قسمت بعدی»، چرخش آزاد/قفل افقی، pause خودکار در پس‌زمینه و ادامهٔ تماشا از موقعیت ذخیره‌شده
- پروفایل کودک (نام نمایشی + آواتار، فقط محلی) و آمار با شمارندهٔ متحرک
- قفل والدین با مسئلهٔ تصادفی؛ بدون PIN ثابت + قفل ۳۰ ثانیه‌ای پس از سه پاسخ نادرست
- تنظیمات والدین: تم سه‌حالته، «کاهش حرکت» برای گوشی‌های ضعیف، پخش خودکار و تأیید دوباره در عملیات حساس
- حالت‌های Loading (Shimmer)، Empty و Error برای جریان‌های اصلی + تست‌های واحد و widget flow
- طراحی واکنش‌گرا با گرید تطبیقی برای موبایل و تبلت
- صفحهٔ «درباره ما» اختصاصی Parsa Apps با هالهٔ طلایی متحرک و لینک رسمی تلگرام

## معماری

```
lib/
├── core/
│   ├── navigation/        # ترنزیشن یکنواخت صفحات (app_routes)
│   ├── services/          # SharedPreferences wrapper
│   ├── theme/             # Design tokens، تم روشن/تاریک و Motion tokens
│   └── utils/             # RTL، ارقام فارسی، نرمال‌سازی متن و System UI
├── data/
│   ├── models/            # CartoonModel، EpisodeModel و ChildProfileModel
│   ├── providers/         # Riverpod state و composition root
│   └── repositories/      # LocalCartoonRepository
├── domain/
│   └── repositories/      # قرارداد CartoonRepository
└── presentation/
    ├── global_widgets/    # Parental Gate
    ├── pages/             # صفحات و جریان‌های کاربر
    └── widgets/           # کارت، artwork برداری، بنر منتخب، ماسکٔ رابط و skeleton
```

UI فقط providerها را می‌خواند؛ provider کاتالوگ را از قرارداد `CartoonRepository` می‌گیرد. برای اتصال backend، یک repository جدید پیاده‌سازی و در `cartoonRepositoryProvider` جایگزین کنید؛ صفحه‌ها تغییر نمی‌کنند.

## پیش‌نیازها

- Flutter **3.19 یا بالاتر**
- Dart **3.2 یا بالاتر**
- Android SDK با `compileSdk 34`
- دستگاه یا شبیه‌ساز Android با حداقل API 21

## اجرا

```bash
flutter pub get
flutter analyze

```

هر سه فرمان در GitHub Actions (workflow `CI Verify`) روی هر push و PR اجرا می‌شوند و بیلد `apk --debug` هم راستی‌آزمایی می‌شود.


## ساخت خروجی Android

```bash
flutter build apk --release
flutter build appbundle --release
```

شناسهٔ فعلی برنامه `ir.parsaapps.kartoniya` است.

### امضای انتشار

فایل `android/key.properties` عمداً داخل Git نگه‌داری نمی‌شود. برای امضای فروشگاهی، آن را فقط روی محیط امن خودتان بسازید:

```properties
storePassword=YOUR_STORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=YOUR_KEY_ALIAS
storeFile=/absolute/path/to/release.keystore
```

در نبود این فایل، Gradle یک APK release **با امضای debug فقط برای smoke test CI** می‌سازد. چنین فایلـی برای کافه‌بازار یا گوگل‌پلی قابل انتشار نیست.

## محتوا و پخش ویدئو

`LocalCartoonRepository` نمونهٔ محلی کاتالوگ است و برای تست فنی player از یک URL عمومی Flutter استفاده می‌کند. این URL محتوای تجاری کارتونیا نیست. پیش از انتشار:

1. URLهای قسمت را با CDN HTTPS و محتوای دارای حق پخش جایگزین کنید.
2. در صورت نیاز، repository API را با احراز هویت کوتاه‌عمر و cache امن پیاده‌سازی کنید.
3. رده‌بندی سنی، اطلاعات صاحب اثر و سیاست گزارش محتوا را برای هر عنوان ثبت کنید.
4. روی شبکهٔ ضعیف، قطع اینترنت و دستگاه‌های پایین‌رده تست دستی انجام دهید.

## حریم خصوصی و امنیت

- برنامه در نسخهٔ فعلی حساب کاربری، تبلیغ‌کننده یا analytics ندارد.
- فقط نام نمایشی والد، انتخاب تم، علاقه‌مندی‌ها و درصد ادامهٔ تماشا در `SharedPreferences` همان دستگاه ذخیره می‌شوند.
- مجوز Storage درخواست نمی‌شود و `requestLegacyExternalStorage` حذف شده است.
- ارتباط ویدئویی باید صرفاً HTTPS باشد.
- کلید امضای Android از repository حذف و در `.gitignore` محافظت شده است.

## تست‌های موجود

```bash
flutter test
```

- یکسان‌سازی جست‌وجوی فارسی/عربی و مرتب‌سازی مرتبط‌بودن
- اعتبار پایهٔ کاتالوگ محلی و URLهای HTTPS قسمت‌ها
- `AppPreferences`: علاقه‌مندی، تم، پیشرفت کلمپ‌شده، JSON خراب و پروفایل کودک
- Notifierها: toggle علاقه‌مندی، prune شناسه‌های نامعتبر، آستانه‌های ادامهٔ تماشا، کاهش حرکت
- مدل‌ها: `copyWith`، برچسب مدت قسمت و ارقام فارسی
- جریان‌های widget: اسپلش→آن‌بوردینگ→خانه در اولین اجرا، ذخیرهٔ قلب کارت، باز/بسته‌شدن قفل والدین با پاسخ درست/غلط و رندر تنظیمات

## انتشار در کافه‌بازار و گوگل‌پلی

1. `applicationId`، نام، آیکون، اسکرین‌شات‌ها و سیاست حریم خصوصی را نهایی کنید.
2. فقط محتوا و تصاویر دارای مجوز را در کاتالوگ قرار دهید.
3. keystore انتشار را در محیط امن CI یا local تنظیم کنید.
4. AAB امضاشده بسازید: `flutter build appbundle --release`.
5. روی چند نسخهٔ Android و دستگاه واقعی، onboarding، قفل والدین، بازگشت از player، حالت تاریک و قطع اینترنت را تست کنید.
6. فرم‌های رده‌بندی سنی، Data Safety و اطلاعات پشتیبانی فروشگاه را تکمیل کنید.

جزئیات معماری و نقشهٔ راه صدمرحله‌ای در [`docs/ARCHITECTURE_FA.md`](docs/ARCHITECTURE_FA.md) و [`docs/ROADMAP_FA.md`](docs/ROADMAP_FA.md) آمده است.
