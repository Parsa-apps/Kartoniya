# 🎬 کارتونیا — فهرست و پخش محتوای کودک با همراهی والدین

**کارتونیا** یک اپلیکیشن Flutter فارسی و RTL برای مرور فهرست کارتون‌ها و بازکردن ویدئوهاست. رابط برای استفادهٔ خانوادگی طراحی شده است؛ پرسش والدین فقط دسترسی اتفاقی به بعضی بخش‌ها را کاهش می‌دهد و جایگزین امنیت حساب یا نظارت بزرگ‌تر نیست.

> وضعیت کد: نسخهٔ ۱.۲.۱+4 با Design System و Motion System یکپارچه (پالت آبی/فیروزه‌ای/بنفش/مرجانی/طلایی، ماسکٔ برداری «فِلَک»، بنر پیشنهاد، Hero Transition، نوار پیمایش اختصاصی و کاهش حرکت)، کاتالوگ محلی، پخش رسمی embed آپارات و پخش native برای URLهای مستقیمِ مجاز، تنظیمات محلی و repository قابل جایگزینی با API/CMS. ۱۶ لینک آپارات در کاتالوگ ثبت شده‌اند؛ رده‌بندی سنی رسمی، بازبینی کامل محتوا و مجوز انتشار تجاری هنوز تأیید نشده‌اند.

## قابلیت‌ها

- رابط **Material 3**، فارسی و کاملاً RTL با حالت روشن/تاریک منسجم
- **تایپوگرافی:** Vazirmatn برای متن + گونهٔ رسمی Round-Dots همین خانواده برای تیترها؛ هر دو تحت SIL OFL 1.1 و به‌صورت محلی باندل شده‌اند؛ اولین اجرا برای فونت به شبکه نیاز ندارد.
- **عمق بصری:** ماسک و پوسترها نقاشی برداری دوبعدی با سایه/گرادیان faux-3D هستند؛ مدل یا موتور سه‌بعدی ندارند.
- **Motion System** مشترک در `AppMotion`: ورود پلکانی، مقیاس لمسی، Hero Transition بنر→جزئیات و بازخورد علاقه‌مندی؛ loopها، shimmer و نشانگرهای انتظار در برابر کاهش حرکت/ترجیح سیستم واکنش نشان می‌دهند.
- خانه با بنر پیشنهادهای ویراستاری، دسته‌بندی‌ها، علاقه‌مندی‌های واقعیِ ذخیره‌شده روی دستگاه و ادامهٔ تماشا فقط برای پخش native که پیشرفت آن را گزارش می‌کند
- Splash کوتاه و قابل‌ردکردن، همراه نشان و ماسکٔ رابط؛ Onboarding سه‌مرحله‌ای با توضیح محدودیت‌های میزبان و پرسش والدین
- دسته‌بندی با کاشی‌های رنگی و شمارش واقعی، جست‌وجوی فارسی با normalize حروف، فیلتر دسته و نتایج مرتب‌شده
- علاقه‌مندی‌ها و ادامهٔ تماشا با پاک‌سازی خودکار شناسه‌های نامعتبر هنگام بارگذاری کاتالوگ
- پخش native با `video_player`: seek، حجم صدا، دابل‌تپ ۱۰ ثانیه‌ای، autoplay اختیاری برای URLهای پشتیبانی‌شده، توقف در پس‌زمینه و پیشرفت محلی؛ embed آپارات فقط کنترل‌های رسمی خودش را نشان می‌دهد و progress/autoplay اپ برای آن فعال نیست
- پروفایل کودک (نام نمایشی + آواتار، فقط محلی) و آمار با شمارندهٔ متحرک
- پرسش والدین برای کاهش دسترسی اتفاقی، بدون PIN ثابت + مکث ۳۰ ثانیه‌ای پس از سه پاسخ نادرست؛ سازوکار امنیتیِ غیرقابل‌دورزدن نیست
- تنظیمات والدین: تم سه‌حالته، «کاهش حرکت» برای گوشی‌های ضعیف، پخش خودکار و تأیید دوباره در عملیات حساس
- حالت‌های Loading (Shimmer)، Empty و Error برای جریان‌های اصلی + تست‌های واحد و widget flow
- طراحی واکنش‌گرا با گرید تطبیقی برای موبایل و تبلت
- صفحهٔ «دربارهٔ ما» با خلاصهٔ حریم خصوصی و لینک پشتیبانیِ پشت پرسش والدین؛ صفحهٔ جزئیات، رفتار فعلی کد را شرح می‌دهد اما سیاست حقوقی نهاییِ فروشگاه نیست
- صفحهٔ والد-محورِ وضعیت خرید (پشت قفل والدین)؛ بدون paywall، قیمت، SKU، entitlement یا SDK پرداخت تا تصمیم‌های محصول/فروشگاه تأیید شوند

## معماری

```
lib/
├── core/
│   ├── navigation/        # ترنزیشن یکنواخت صفحات (app_routes)
│   ├── services/          # SharedPreferences wrapper
│   ├── theme/             # Design tokens، تم روشن/تاریک و Motion tokens
│   └── utils/             # RTL، ارقام فارسی، نرمال‌سازی متن و System UI
├── data/
│   ├── models/            # CartoonModel، EpisodeModel و ChildProfileModel
│   ├── providers/         # Riverpod state و composition root
│   └── repositories/      # LocalCartoonRepository
├── domain/
│   └── repositories/      # قرارداد CartoonRepository
└── presentation/
    ├── global_widgets/    # Parental Gate
    ├── pages/             # صفحات و جریان‌های کاربر
    └── widgets/           # کارت، artwork برداری، بنر منتخب، ماسکٔ رابط و skeleton
```

UI فقط providerها را می‌خواند؛ provider کاتالوگ را از قرارداد `CartoonRepository` می‌گیرد. برای اتصال backend، یک repository جدید پیاده‌سازی و در `cartoonRepositoryProvider` جایگزین کنید؛ صفحه‌ها تغییر نمی‌کنند.

## اجرا

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

Workflow موجود [`apkmaker.yml`](.github/workflows/apkmaker.yml) روی push و اجرای دستی، Flutter 3.19.6 را به‌کار می‌گیرد و `pub get`، `flutter test` و APK release را اجرا می‌کند؛ در آن workflow فعلاً `flutter analyze` اجرا نمی‌شود و PR trigger هم تعریف نشده است.


## ساخت خروجی Android

```bash
flutter build apk --release
flutter build appbundle --release
```

شناسهٔ فعلی برنامه `ir.parsaapps.kartoniya` است.

### امضای انتشار

فایل `android/key.properties` عمداً داخل Git نگه‌داری نمی‌شود. برای امضای فروشگاهی، آن را فقط روی محیط امن خودتان بسازید:

```properties
storePassword=YOUR_STORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=YOUR_KEY_ALIAS
storeFile=/absolute/path/to/release.keystore
```

در نبود این فایل، Gradle یک APK release **با امضای debug فقط برای smoke test CI** می‌سازد. چنین فایلـی برای کافه‌بازار یا گوگل‌پلی قابل انتشار نیست.

## محتوا و پخش ویدئو

`LocalCartoonRepository` شامل ۸ بخش و ۱۶ ویدیوی متمایز آپارات است؛ فایل نمونهٔ زنبور حذف شده است. عنوان قسمت، مدت و نام منتشرکننده بر اساس صفحات آپارات ثبت شده‌اند. فهرست کامل: [منابع محتوا](docs/aparat-content.md).

- صفحهٔ HTTPS پایدار هر ویدیو به embed رسمی آپارات در WebView باز می‌شود؛ لینک موقت CDN استخراج یا ذخیره نمی‌شود.
- برنامه کنترل سفارشیِ seek/صدا/پخش روی embed تزریق نمی‌کند و gesture policy میزبان را تغییر نمی‌دهد؛ کنترل‌های embed فقط در صورت ارائهٔ خود میزبان در دسترس‌اند.
- انتخاب قسمت درون برنامه ممکن است؛ resume، progress و autoplay اختصاصی برنامه برای Aparat پشتیبانی نمی‌شوند. seek/volume native فقط برای `video_player` و URL مستقیمِ مجاز است.
- پخش از سرویس بیرونی است؛ سیاست داده، تبلیغات و دسترس‌پذیری میزبان خارج از کنترل کارتونیاست. برچسب منبع/منتشرکننده در رابط کودک نمایش داده نمی‌شود.
- ثبت لینک عمومی به معنی دریافت مجوز بازنشر یا تأیید مناسب‌بودن برای کودک نیست. بازبینی کامل والد/مدیر محتوا، ردهٔ سنی و حقوق استفاده پیش از انتشار تجاری لازم است.
- پخش واقعی روی Android، lifecycle، قطع اینترنت، Android System WebView و کنترل‌های واقعی Aparat باید دستی آزموده شوند؛ موفقیت بیلد جایگزین آزمون دستگاه نیست.

## حریم خصوصی و امنیت

- کد برنامه حساب کاربری، analytics یا شبکهٔ تبلیغاتیِ اختصاصی ندارد؛ embed آپارات سرویس ثالث است و ممکن است دادهٔ فنی، کوکی و تبلیغات خودش را داشته باشد.
- نام نمایشی والد/کودک، آواتار، تم، تنظیم کاهش حرکت، autoplay، علاقه‌مندی‌ها، وضعیت onboarding و پیشرفت پخش native در `SharedPreferences` همان دستگاه ذخیره می‌شوند؛ storage رمزگذاری‌شده نیست، cloud sync وجود ندارد و استفاده از نام مستعار توصیه می‌شود. progress قدیمی ممکن است تا پاک‌کردن دستی باقی بماند.
- مجوز Storage درخواست نمی‌شود و `allowBackup=false` از نسخهٔ فعلیِ داده‌های محلی پشتیبان نمی‌گیرد.
- embed فقط HTTPS است. کلید امضای Android از repository خارج و در `.gitignore` محافظت شده است.

## وضعیت خرید

کد هیچ SDK پرداخت/اشتراک، شناسهٔ محصول، قیمت یا entitlement ندارد. صفحهٔ «وضعیت خرید» فقط برای والد پس از پرسش والدین قابل دسترسی است و پیش‌نیازها را نشان می‌دهد؛ خرید هنوز غیرفعال است. برای فعال‌سازی باید فروشگاه مقصد (بازار/مایکت)، محصولات و قیمت‌های واقعی، نسخهٔ SDK سازگار، اعتبارسنجی رسید، لغو و بازیابی خرید، مزایای محصول و مجوز محتوا با مالک محصول نهایی شوند. هیچ تراکنشی در این نسخه انجام نمی‌شود.

## تست‌های موجود

```bash
flutter test
```

- یکسان‌سازی جست‌وجوی فارسی/عربی و مرتب‌سازی مرتبط‌بودن
- اعتبار پایهٔ کاتالوگ محلی و URLهای HTTPS قسمت‌ها
- `AppPreferences`: علاقه‌مندی، تم، پیشرفت کلمپ‌شده، JSON خراب و پروفایل کودک
- Notifierها: toggle علاقه‌مندی، prune شناسه‌های نامعتبر، آستانه‌های ادامهٔ تماشا، کاهش حرکت
- مدل‌ها: `copyWith`، مجموع زمان قسمت‌های فهرست‌شده، اعتبارسنجی URL آپارات و ارقام فارسی
- کاتالوگ: شناسه‌های یکتا، URLهای HTTPS/مدت واقعی قسمت و نبود نشان‌های تازگی/رتبه/ردهٔ سنیِ تأییدنشده
- جریان‌های widget: مسیر اولین اجرا، ردکردن اسپلش، ذخیرهٔ علاقه‌مندی، قفل والدین، صفحهٔ وضعیت خرید بدون قیمت و رندر تنظیمات

## انتشار در کافه‌بازار و گوگل‌پلی

1. `applicationId`، نام، آیکون، اسکرین‌شات‌ها و سیاست حریم خصوصی را نهایی کنید.
2. فقط محتوا و تصاویر دارای مجوز را در کاتالوگ قرار دهید.
3. keystore انتشار را در محیط امن CI یا local تنظیم کنید.
4. AAB امضاشده بسازید: `flutter build appbundle --release`.
5. روی چند نسخهٔ Android و دستگاه واقعی، onboarding، قفل والدین، بازگشت از player، حالت تاریک و قطع اینترنت را تست کنید.
6. فرم‌های رده‌بندی سنی، Data Safety و اطلاعات پشتیبانی فروشگاه را تکمیل کنید.

جزئیات معماری و نقشهٔ راه صدمرحله‌ای در [`docs/ARCHITECTURE_FA.md`](docs/ARCHITECTURE_FA.md) و [`docs/ROADMAP_FA.md`](docs/ROADMAP_FA.md) آمده است.
